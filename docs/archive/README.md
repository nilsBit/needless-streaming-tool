# Archive

Specs, plans, and state documents from the Superpowers-based workflow used until July 2026.

**These are history, not process.** They record what was built and the reasoning at the
time. Do not use them as templates for new work, and do not treat their instructions as
current — several were already stale when archived. `state/streamdeck-plugin-rebuild-state.md`
in particular predates the rename to NST and refers to files under their old
`com.thelab.toolkit` names.

Anything still open from these documents was moved to GitHub Issues when the archive was
created. **GitHub Issues is the source of truth for open work** — if something here is not
an issue, it is either done or was consciously dropped.

They stay in the repo because they explain *why* parts of the codebase look the way they
do, which git history alone conveys poorly.

For current process, see `CLAUDE.md` at the repo root.
